# YSClaude 核心测试用例

## 测试范围

首批覆盖对话流式协议、Agent 工具调用、取消/超时、数据诊断和 Android 权限链路。优先级采用 P0（阻塞核心流程）、P1（影响主要能力）、P2（局部体验）。

| ID | 优先级 | 模块 | 场景与步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| SSE-001 | P0 | 流式响应 | 将一个 JSON 事件拆成两个网络分片输入 | 首段保留在 buffer；次段到达后只解析一次完整事件 |
| SSE-002 | P0 | 流式响应 | 流中混入损坏 JSON，随后发送合法事件 | 损坏事件被跳过，后续合法事件继续输出 |
| SSE-003 | P1 | 流式响应 | 分别输入 LF、CRLF、无末尾换行的数据 | 三种边界均正确解析，结束时 flush 残留事件 |
| SSE-004 | P1 | 流式响应 | 输入 keep-alive 注释、空行和 `[DONE]` | 不产生正文或异常 |
| TOOL-001 | P0 | 工具调用 | 函数名按 `get_`、`weather` 两段返回 | 合并为唯一的 `get_weather` 调用 |
| TOOL-002 | P0 | 工具调用 | 多个调用的 delta 数组位置变化但 ID 不变 | 按调用 ID 归并，不发生参数串线 |
| TOOL-003 | P1 | 工具调用 | 网关把两个已知工具名粘连返回 | 拆成两个调用，参数保留给最后一个调用 |
| AGENT-001 | P0 | Agent Loop | 工具连续调用达到最大轮数 | 停止继续调用并返回明确的上限结果 |
| AGENT-002 | P0 | Agent Loop | 子 Agent 执行中停止父任务 | AbortSignal 向下传播，子任务停止且不再写入结果 |
| AGENT-003 | P1 | Agent Loop | 单个工具抛出异常 | 异常转换为结构化 tool_result，主循环可继续处理 |
| CHAT-001 | P0 | 聊天 | 发送消息后立即停止生成 | UI 停止追加内容，API 事件标记为 aborted |
| CHAT-002 | P1 | 数据诊断 | 数据库存在空 Assistant 消息 | 诊断页计数准确，可定位并清理目标消息 |
| CHAT-003 | P1 | 数据诊断 | 同一会话出现重复时间戳 | 诊断页标记重复组，跳转到对应消息 |
| AND-001 | P0 | Android 权限 | 拒绝无障碍或 Shizuku 权限后调用设备工具 | 不执行高权限动作，返回可理解的权限错误 |
| AND-002 | P1 | Android 服务 | 前台服务运行时切换前后台并重新进入 | 服务状态与 UI 一致，不重复启动、不丢失任务 |
| AND-003 | P1 | AIDL | Shell 服务 disconnected/binding died | 请求有界失败或重连，不无限等待 |

## 回归准入

- P0 用例必须全部通过；P1 不得存在未评估的阻塞性缺陷。
- 提交前运行 `npm run typecheck` 与 `npm run test:coverage`。
- 当前纯函数测试模块覆盖率门槛：行/函数/语句不低于 85%，分支不低于 80%。
- 修复协议、Agent Loop 或数据库相关缺陷时，必须增加对应自动化用例或记录无法自动化的原因。
