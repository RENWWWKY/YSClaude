# YSClaude 真实缺陷案例

以下案例来自仓库已合入的修复提交，用于回归测试、面试讲解和后续同类问题预防。提交哈希可用于查看完整代码差异。

## 1. 工具调用与思考内容横向溢出

- **提交**：`cdcfae0`
- **现象**：工具名称、参数或 Thinking 内容较长时，消息行超出聊天气泡可用宽度。
- **根因**：React Native Flex 子项缺少 `minWidth: 0` 与收缩约束，长文本按自身最小内容宽度撑开父容器。
- **修复**：为工具行和 Thinking 容器增加 `flexShrink: 1`、`minWidth: 0`、`maxWidth: 100%`。
- **回归**：分别输入长英文无空格文本、长 JSON、中文长句；验证窄屏、字体放大和展开/收起状态下均不横向溢出。

## 2. 滚动到底部后连续加载全部较新消息

- **提交**：`18c534f`
- **现象**：加载一页较新消息后，列表仍处于 `onEndReachedThreshold`，FlatList 会立即继续请求后续分页。
- **根因**：分页加载没有与新的用户拖动动作绑定，追加数据会重复触发 `onEndReached`。
- **修复**：增加一次性 armed 状态，只允许用户开始新的拖动后再加载一页，并在触发时立即消费该状态。
- **回归**：准备多页历史消息；单次拖动只加载一页，静止时不继续请求，再次拖动后才加载下一页。

## 3. 前台状态仍弹出回复通知

- **提交**：`bf5c76a`
- **现象**：应用处于前台时仍显示系统通知、播放提示音，造成与聊天页反馈重复。
- **根因**：通知 handler 固定开启 alert/banner/sound，且缓存的 AppState 可能不是调用时的最新值。
- **修复**：判断最新 `AppState.currentState`，仅在非 active 状态展示通知和声音。
- **回归**：分别在前台、后台、切换瞬间接收回复；前台只更新 UI，后台展示通知，切回前台不重复提示。

## 4. 切换会话后滚动位置异常

- **提交**：`8fe7af0`
- **现象**：切换对话时沿用旧列表的滚动处理状态，可能无法定位到新会话期望位置。
- **影响**：用户进入会话后看到旧位置或发生不必要的自动滚动，长会话更明显。
- **回归**：在短会话、长会话及中间楼层间连续切换，验证首次定位、返回底部和手动滚动互不干扰。

## 5. 回复按钮与空 Assistant 消息持久化异常

- **提交**：`7d4dfb8`
- **现象**：部分回复/停止场景会保留没有有效正文的 Assistant 消息，干扰楼层、历史记录与后续上下文。
- **影响**：数据库出现空消息，聊天诊断计数异常，重新打开会话时可能出现空白气泡。
- **回归**：覆盖发送后立即停止、接口无正文、仅工具调用、生成失败与重新回复；确认仅符合协议需求的消息被保留。

## 6. 系统浏览器认证后待发送输入丢失

- **提交**：`c146fe6`
- **现象**：网页认证跳转到系统浏览器后，返回应用时用户原先准备提交的输入可能丢失。
- **风险点**：跨应用生命周期、WebView 与系统浏览器切换、异步认证回调共同修改输入状态。
- **回归**：认证前输入文字并附加内容，完成/取消认证后返回；验证草稿、附件和焦点状态按产品预期保留。

## 缺陷回归原则

- 每个修复至少保留一个正常场景和一个触发原缺陷的边界场景。
- 涉及异步、滚动和生命周期的缺陷必须重复执行，并覆盖快速操作。
- 可提取为纯函数的逻辑优先加入 Vitest；依赖原生 UI 的场景进入 Android E2E 用例集。
